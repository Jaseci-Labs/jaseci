- **Breaking (compiler internals): one product table schedules every pass**: each compiler pass now declares the analysis facts it requires and provides on its own class, and a single `PRODUCTS` table in `jaclang.compiler.driver.pipeline` defines every schedule (IR, analysis, boundaries, client, native IR, bytecode, format, lint and the utility products). `require(program, module, product)` is the only way passes run and `invalidate(program, module, product)` drops a product with its dependents. Removed: `PASS_CONTRACTS`, the `get_*_sched` and `get_py_code_gen` schedule builders, `register_product_schedule` / `register_codegen_backend`, `CompilationPhase`, `UtilityProduct` (merged into `CompilationProduct`) and `JacProgram.run_schedule`. Code that ran a schedule directly should request the product instead.
