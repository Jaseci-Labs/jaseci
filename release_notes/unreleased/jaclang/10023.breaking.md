- **The Ops Console's Role is bound to a dedicated `<app>-ops` ServiceAccount that only the gateway runs as**: with `ops_console = true` and no `service_account_name`, the Role was bound to the namespace's `default` ServiceAccount, so every pod that names no account of its own inherited the console's rights. With the console on, the gateway now runs as `<app>-ops` rather than `service_account_name` (a gateway that got a cloud identity from `service_account_name` must pre-create `<app>-ops` with those annotations), `service_account_name = "<app>-ops"` fails the deploy, and the identity running the deploy needs permission to create ServiceAccounts. Redeploying rolls the gateway once. See the Breaking Changes page for the migration.
