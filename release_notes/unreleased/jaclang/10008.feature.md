- **Feature: `Document` sends a PDF to a `by llm` function**: byLLM had no media type for documents, so a PDF passed as an `Image` failed at the provider or in Pillow. `Document(path_or_bytes, filename=None)`, exported from `jaclang.byllm.lib`, reads a PDF and sends it as a `file` block that LiteLLM maps to each provider's document input. The content is checked rather than the extension: anything that is not a PDF raises a `ValueError` that points to `Text`, which carries text-like files such as `.md`, `.txt` and `.csv`. A tool may return a `Document`; like an image, it reaches the model in the user turn after the tool result instead of inside the tool message.
