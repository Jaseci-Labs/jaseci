- **Fix: `jac run --dev` finds a kit's bun that has no version record, and says so when the client cannot start**: a source checkout rerouted from a kit packed before the artifact router (including v0.37.25) judged the kit's bun "of unknown version", because its version was read only from a record those kits do not ship, so the Vite dev server never started. With no record, the probe now asks the binary for its version. When the client dev server does fail, the banner shows the API URL, says "Server ready (API only)" and gives the reason, instead of advertising an app URL nothing serves.
