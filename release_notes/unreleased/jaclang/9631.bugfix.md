- **Fix: a native override that an imported base's own methods would skip is refused (E5113)**: Which classes carry a vtable is decided per module, so a root class nothing in its own module derives from is lowered without one. When another module subclassed it and overrode a method, a base method the subclass inherits still bound its `self.m()` straight to the base's own `m`: `TreeSource().spot(1.0)` ran `Source.trace` natively and `TreeSource.trace` on the server pathway, with no diagnostic. The native backend now reports E5113 at the override when an inherited method of such a base calls the overridden method on `self`, naming the base method that would skip it. An override no base body dispatches to compiles as before. Declaring the base method abstract (`abst`) reserves dispatch for implementations in other modules and is the shape the help points to.
