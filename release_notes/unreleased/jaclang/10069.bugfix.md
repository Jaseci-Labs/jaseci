- **Fix: a workspace app's dev build errors reach the Vite error overlay**: The hot reloader wrote `.jac-status.json` and `.jac-force-reload` beside the app's compiled output (`.jac/client/<app>/`), but the dev Vite config reads them from `.jac/client/`. A failed build showed no overlay, an export-set change never forced a reload, and Vite reloaded the page on every status write instead. The reloader now writes both files to the directory the Vite config reads them from.
