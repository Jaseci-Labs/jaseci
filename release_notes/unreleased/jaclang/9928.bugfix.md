- **Fix: native `sum` over a `bytearray` no longer adds bytes of 128 and above as negative numbers, and a float `sum` keeps the terms a running total rounds away**: A bytearray is a list of `u8` underneath, and `sum` sign-extended its elements like any other narrow integer, so `sum(bytearray([1, 2, 250, 255]))` returned -4 natively and 508 in Python. Bytes and bytearray operands are now summed as unsigned bytes. A `sum` that accumulates as a float, over a list as well as over bytes, added each term straight into the total, so `sum([1.0, 1.0], 1e16)` returned `1e16` natively and `1.0000000000000002e+16` in Python, which carries each addition's rounding error beside the total (Neumaier's compensated sum) and folds it in at the end. The native loop now does the same, including CPython's plain first addition when an int `start` meets a list of floats.
