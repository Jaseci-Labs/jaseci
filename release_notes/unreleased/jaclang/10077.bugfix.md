- **Fix: a kernel without the stub catalog builds it instead of failing every analysis**: a current checkout kernel with no stub catalog made every analysis fail with `Python sources are parsed by the host`, because the kernel reads typeshed only through the catalog. jac now builds the catalog the first time a kernel session needs it, says so, and goes on with the kernel; concurrent jac processes build it once. When it cannot be built (a sealed install, an unwritable cache, a failed build), the command stops with the cause and `jac native build stubcat` to run. `jac native build kernel` builds the catalog first.
