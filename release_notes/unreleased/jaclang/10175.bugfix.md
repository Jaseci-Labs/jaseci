- **Fix: native builds started from a directory with an `__init__.py` work on kits with the native compiler kernel**: `os.path.dirname` in native code returned `""` for a path directly under the root (`"/home"`) and for the root itself, where Python returns `"/"`. The compiler's own directory walks run inside the kernel, so they went one step past the root and read the working directory, and a native build started from a package directory failed with E0005 in generated imports. `dirname` now follows `posixpath`.
