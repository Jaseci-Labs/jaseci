- **Performance: Postgres parses each statement once per session**: the wire client sent every statement as an unnamed `Parse`, so Postgres parsed and planned it again on every execution, and parking a pooled connection ran `DISCARD ALL`, which dropped prepared statements too. Statements are now named on first use and reused by `Bind`/`Execute` (up to 512 per session), and parking resets only advisory locks, settings, `LISTEN`, temp tables and sequence state. With the default worker count, Postgres CPU per request on Amplify's data routes fell 11-23% and throughput rose up to 39% (together with #10148).
