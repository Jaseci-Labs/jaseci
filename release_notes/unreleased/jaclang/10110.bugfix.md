- **Fix: a dev hot reload can no longer race a request's module reload**: The hot reloader held the preparation lock only while re-preparing, not while it tore down and re-initialized the app, so a waiting request could reload into a half-torn app and fail with `ImportError`. Module reloads other than the dev endpoint refresh (such as `JacModule.update_walker`) also reloaded without the lock while holding Python's import lock. The whole hot reload and every `jac_import` reload now hold the lock, and a compile leaving early on one thread no longer clears the closure options of a compile still running on another.
