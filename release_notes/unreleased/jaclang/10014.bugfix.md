- **Fix: loading stored nodes no longer resolves each node's class through the filesystem**: every anchor a request loaded looked its class up again, and inside an application that meant `realpath` and module lookups per row. The class is now resolved once per application and type and reused while its module still holds it, so a hot reload still picks up the new class. On a route that loads a few hundred nodes, server CPU per request dropped by about a quarter.
