- **Feature: `__list_data_ptr(lst)`, the element buffer of a native `int` or `float` list**: a new compiler intrinsic returns the address of the list's element buffer as an integer, for the `__mem_load_i64` / `__mem_store_i64` accessors. Each `lst[i]` is a checked access that reloads the list header, checks the bounds and handles a negative index; code that already owns its indices, such as an interpreter's register file, can now read or write an element with one load or store. The address holds until the list grows past its capacity, and nothing checks the index. A list of objects or strings, whose elements are reference counted, and a temporary list, which is freed with the statement, are refused with `E5095`. A register-file interpreter loop runs 16% fewer instructions (5–6% faster), and js_engine's vite build of the site 2.4% faster with its register file read this way.
