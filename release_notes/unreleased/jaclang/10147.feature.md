- **Native binaries, libraries and wasm modules are linked by LLD, built into jac**: `jac build --native` (and every native unit jac links for itself) now runs LLVM's own linker in-process, in place of jac's four hand-written ELF, Mach-O, PE and wasm linkers. jac still needs no system linker. Linux executables are position-independent (PIE), a C floor archive contributes only the members a program reaches, and Windows and macOS targets cross-link from any host with import libraries and text stubs jac writes itself.
  **Breaking change**: the `build.py` of a project exported with `jac build --as source` links wasm with the toolchain's `wasm-ld` (found next to `$CC`, or named by `$WASM_LD`); its C path already used the system compiler.
