- **Fix: a static field read through a class value follows the runtime class natively**: with `p: type[Base]` holding a subclass, `p.field` compiled natively read `Base`'s own value while the Python tier read the subclass override. Class records now carry each class's static fields, and the read dispatches on the class the value holds, across modules; an override stored as the payload of a declared optional is wrapped, and any other layout mismatch raises `TypeError` rather than reading the wrong memory. Diagnostic messages whose values contain braces (an LLVM struct type such as `{i64}`) no longer print as an unfilled template.
