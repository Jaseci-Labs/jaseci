- **`jac studio`**: a compiler-backed terminal workspace for working on a Jac codebase with coding agents. It loads the project into a graph of packages, modules, archetypes, abilities and impls joined by the archwire wiring, and `jac studio model` prints or dumps it. Osprey, the Jac TUI framework it is built on, now lives in the repository at `jac/jaclang/osprey`.
