- **Fix: a connect's attribute value read from a field stays alive until it is stored**: in native rc and managed builds, a typed connect that evaluates its attribute values before storing them (a single-edge connect whose edge type requires some of the named fields, or a connect through a list of nodes) held a value read from a field without a reference. In `a +>:E:note=h.text, kind=reset(h):+> b`, `reset` replacing `h.text` freed the string before `note` was stored, and the edge read freed memory. Each held value now keeps its own reference until the edge takes it.
