- **Fix: native wasm modules no longer import the runtime floor from the host**: the stdlib's `__jac_*` floor functions (math's `fmadd` among them) are now defined inside every wasm module, so a module using `math.gamma` loads again. Native `os.path.expanduser("~user")` also resolves accounts whose passwd record is larger than 4 KiB, and `jac native require kernel@<osarch>` for another target no longer accepts the host's installed kernel.
