- **Fix: a `list[Image]` argument to a `by llm` function is sent as images**: a list of `Image` or `Video` arguments was written into the prompt text as its Python repr and never reached the model as media, and a System One call carrying one tried to put it in the state. A non-empty list made only of media is now sent as one block per item, in order, with the parameter's sem emitted once ahead of the first, and a call carrying one goes to the fallback model like a single media argument. `Text` is also exported from `jaclang.byllm.lib`.
