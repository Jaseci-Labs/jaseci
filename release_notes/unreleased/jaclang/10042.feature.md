- **byLLM: applied compactions are reported to the caller**: a tool-calling `logging=True` stream or `stream_handler` receives a `compaction` event (`reason`, `by`, message and token sizes before and after, `iteration`) for each compaction byLLM applies, and every invocation lists them in the `compactions` field of its telemetry record. A compaction that is discarded because it did not reduce the history still produces neither.
