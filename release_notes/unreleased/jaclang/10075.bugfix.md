- **Fix: a checkout kernel loads without the OpenSSL development package**: when the static C floor is not built, a native library or kernel linked against a system C library recorded its unversioned development name (`libcrypto.so`) as a dependency, so `jac native build kernel` produced a kernel that only hosts with `libssl-dev` could load. A link for the running Linux host now records the library's SONAME (`libcrypto.so.3`), as a system linker does.
