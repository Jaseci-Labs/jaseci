- **Fix: `jac check` no longer reports a package's members as Unknown after a cyclic import**: when a module asked for a package that was still compiling in another context program, the checker answered with an empty placeholder and kept it as that package for the rest of the run, so every later `ir.Module` in the same `jac check` worker was Unknown (E1032 / E1053 across the native backend, depending on which worker checked which file first). The re-entrant import guard now returns the in-flight module from the program compiling it, and a module whose compile is still in flight is never cached.
