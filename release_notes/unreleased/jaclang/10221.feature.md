- **Performance: native code finds its exception context without a thread-local lookup while single-threaded**: every function that owns a reference looks up the thread's exception context on entry, and that lookup called `pthread_getspecific` each time, which in a shared library is a call into glibc that LLVM cannot inline. Until the program starts a thread there is only one context, so it is now also kept in a process-wide global and the lookup is a load and a compare; once a thread is started, every lookup takes the thread-local path as before. A shared library run through `jac_main` makes 200 M such calls 15% faster (11% fewer instructions); a static executable, where musl's lookup is already cheap, is unchanged.
