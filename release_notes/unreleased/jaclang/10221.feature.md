- **Performance: native code finds its exception context without a thread-local lookup while single-threaded**: every function that owns a reference looks up the thread's exception context on entry, and that lookup called `pthread_getspecific` each time, which in a shared library is a call into glibc that LLVM cannot inline. Until the program starts a thread there is only one context, so it is now also kept in a process-wide global, and the lookup is a load and a compare with no prologue; the thread-local path is out of line, and once a thread is started every lookup takes it, without touching the global. 200 M such calls run 18% faster in a shared library run through `jac_main` (15% fewer instructions) and 13% faster in a static executable (7% fewer).
