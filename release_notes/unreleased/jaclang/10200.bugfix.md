- **Fix: an app that imports a typed package with compiled `.pyi`-only bindings is compiled by the native kernel**: a package such as `cryptography`, whose compiled extension ships only a `.pyi` stub, made the kernel miss on that stub and hand the whole compile back to the host, so every prepare of such an app paid for the kernel's analysis and then a full host compile. The kernel now gets the stub's interface from the host, as it already did for `.py` modules.
