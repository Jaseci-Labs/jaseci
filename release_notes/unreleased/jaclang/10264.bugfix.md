- **A stale login no longer strands a web app, and a stale LLVM shim can be repaired again**: `jacIsLoggedIn()` drops an expired JWT instead of reporting the user signed in, and any 401 on a call that sent a token clears it (service calls still raise `BridgeRejected`). Importing the LLVM bindings no longer calls into the shim, so `jac native build llvm-shim` runs when the shim is stale or missing. `jac test -t` matches a test name's words literally, so names containing `and`, `or` or `not` can be selected.
