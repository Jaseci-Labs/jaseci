- **Fix: a typed connect builds an edge whose fields have no defaults**: `a +>:E:f=v:+> b` built `E()` and then set the named fields, so an edge type with a field that has no default could not be connected this way. Native code raised `edge type cannot be constructed without arguments` and the Python runtime raised a missing-argument `TypeError`, while `+>:E(f=v):+>` worked. The names the edge's constructor requires are now passed to it, and every other named field is still set afterwards, after `postinit`. This holds in the Python runtime, the jac0 seed tier and native lowering, including list connects and edges with their own `init`.
