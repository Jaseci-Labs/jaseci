- **Build: the precompile pool fits the memory it may actually use**: `jac build` and `jac scale deploy` sized their worker pool from the host's free memory and a fixed 2 GiB per worker, and were OOM-killed on large apps or inside memory-limited containers. The pool now reads the cgroup's limit along the process's own cgroup path and the CPU quota, starts with two workers, and adds workers only while the memory they are measured to use still fits.
