- **Fix: reversing or sorting a list of objects no longer frees its elements**: natively, `list.reverse()` and `list.sort(key=...)` swapped two elements through the list's set helper, which releases the element it overwrites, so the first write freed an element and the second stored it back. Half of a reversed list of objects, lists or dicts was dangling and a keyed sort of objects aborted. The two elements are now stored straight into each other's slots.
