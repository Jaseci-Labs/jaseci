- **Breaking: JacPython drops remote debugging, perf trampolines and the `getaddrinfo` fallbacks, and builds from `main` again.** JacPython is configured without remote debugging (`sys.remote_exec()` reports it was not compiled in, and there is no `_remote_debugging` module) and without perf trampolines (`-X perf` and `sys.activate_stack_trampoline()` report them unavailable). Its table of built-in modules is Jac C data, which restores the links #10153 removed. Tuples are now native Jac (`Objects/tupleobject.c` is gone), and the C API checks, `binascii`, `math.comb`/`math.perm`, `json`, `struct` and the compiler's AST walk follow CPython's fast paths. Native code built with the new `native_tls` and `native_sjlj` options reads thread-local slots as TLS and arms exception frames with LLVM's builtin setjmp. An `isinstance` that walks a class's ancestry remembers the last vtable it missed. A function's write to a wired C global now counts as a use of the wire (E1146).
