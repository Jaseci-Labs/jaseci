- **Fix: `jac run --dev` watches a workspace app's shared directories again**: The dev server took its watch roots from the modules left in the compiler's program hub at startup, which is emptied once a prepare is published (#9985) and never filled when the prepared record is restored, so a workspace app watched only its entry directory and edits to shared modules in sibling directories (`core/` next to `web/`) did not reload. The roots now come from the prepared application itself: every prepared module of the app and of the service apps prepared with it, plus every source file the preparation read, so directories that only browser components come from are watched too.
