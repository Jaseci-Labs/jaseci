- **Performance: native functions that own a reference keep their other locals in registers**: such a function registers an unwind record on entry so that a `raise` crossing it releases what it owns. The record took the address of every local, which kept all of them out of registers: each was a stack slot, reloaded after every call. The record now holds only the locals its cleanup releases, through shadow copies written alongside each store, and every other local can stay in a register. A small interpreter loop runs 12% faster (15.6% fewer instructions), and js_engine's vite build of the site 11% faster.
