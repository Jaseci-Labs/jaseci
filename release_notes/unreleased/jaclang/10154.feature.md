- **Performance: a loop of hops from a query's nodes runs as one hop**: a walker that loops over a query's result and hops from each node (an order list hopping to each order's lines) ran one hop and one row fetch per node. Inside a snapshot transaction the runtime now runs that hop once for all the nodes the query returned and fetches their rows in one batch, with no change to app code. Amplify's order list goes from 502 to 204 statements per request and its p50 from 734 to 487 ms.
