- **Fix: `jac scale` redeploys of unchanged code no longer seal the app again**: every deploy sealed the application from scratch, so a redeploy cost as much as the first deploy. The sealed bundle is now kept under `.jac/seal-cache/`, keyed on the shipped sources, the sanitized `jac.toml` files, the jac binary, the pod architecture, the app name and the fat-bundle setting; a deploy whose inputs all match reuses it and skips the seal.
