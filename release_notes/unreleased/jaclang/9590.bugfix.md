- **Fix: tests no longer constrain where their module is placed.** Placement now reads a module through one view that leaves out `test` blocks (inline or from a `.test.jac` annex), so a test that touches `root`, or a `node` archetype whose only root access is in a test, no longer forces the module under test onto the server; a test that needs the server is placed there on its own while the module stays native, and non-test helpers and imports in a test annex are still weighed.
