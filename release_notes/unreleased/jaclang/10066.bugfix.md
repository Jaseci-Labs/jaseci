- **Fix: `jac check` no longer reports the compiler's own warnings**: a project that imports a compiler module (`jaclang.runtime.runtime`, `jaclang.project.config`, ...) and runs on a jac source checkout got the compiler's lint warnings (hundreds of W0060 pointing into `jaclang/`) in its check output. A dependency that is the compiler's own source no longer adds warnings to an application's program; checking a compiler file still reports them.
