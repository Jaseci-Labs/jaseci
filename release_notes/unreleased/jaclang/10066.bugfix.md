- **Fix: `jac check` no longer reports the compiler's own warnings**: a project that imports a compiler module (`jaclang.runtime.runtime`, `jaclang.project.config`, ...) and runs on a jac source checkout got the compiler's warnings in its check output: hundreds of W0060 from loading those modules, and W1051 from typing their declarations while the application was checked, all pointing into `jaclang/`. Neither path adds warnings located in the compiler's own source to an application's program any more; checking a compiler file still reports them.
