- **Fix: one page can no longer flood `/cl/__error__` with error reports**: the client runtime no longer reports errors whose stack frames all come from a browser extension (`chrome-extension://`, `moz-extension://`, `safari-web-extension://` or `safari-extension://`). Before, an extension that threw in a loop sent one report per throw. Each distinct error is now reported once per page, and a page sends at most 10 reports a minute. The early error handler in a served page skips extension errors too and sends at most 10 reports, and the React Native core uses the same per-page budget.
