- **Fix: a dict literal keyed first by a string variable lowers natively**: a literal such as `{name: None}`, where the key is a parameter or a module global and the literal is the first of its dict type in the module, failed with "Operands must be the same type" and demoted its function to Python (failing a native build that called it); the first key is now normalised from a string view as the first value already was.
