- **Fix: a native kernel build that succeeds can be loaded**: `jac native build kernel` reported success, and `jac native status kernel` said `current`, for a `libjac_compiler.so` that failed to load with `undefined symbol: unit_products_<hash>.unit_products`. Inside the compiler's import cycle, a unit lowered while a dependency was still being built took the dependency's final interface without being lowered again. If that dependency had demoted a function the unit calls to Python, the unit kept a direct call to a symbol that no longer existed. Such a unit is now lowered again against the real interface. A link also refuses objects that reference a unit symbol no unit defines, and the error names the symbol and the unit that uses it, so a library with unresolved unit symbols is never published.
