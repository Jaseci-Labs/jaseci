- **Fix: compiling a module that can never be native no longer re-analyzes its imports from source**: under the native default, a module whose native placement was already ruled out before typing (a Python-only import, an async ability, inline Python) still asked for full dependency trees, which turned off the interface cache for the rest of its compile, so every Jac module it imported was parsed and analyzed again. Only a module that may still be placed native asks for them now. Compiles of such modules, and the compiler test suite, are back to their speed before placement moved after typing.
