- **Fix: `jac check` re-analyzed modules it had already cached**: an empty module (such as an empty package `__init__.jac`) never got a cached interface, so every module importing it, `runtime.jac` included, was re-parsed and re-analyzed by each new process. Separately, a forked check worker could not use the cache on its first file. A warm re-check of an unchanged 26-file package went from 8.6 s to 0.6 s.
