- **Fix: a stale LLVM shim no longer crashes `jac native` or explicitly native code**: after a change to `jac/native`, `build.zig` or the LLVM pin, `jac native status` and `jac native build llvm-shim` crashed at load, because the LLVM binding called the shim while importing, and a web app with native code crashed loading its entry module, because the pass pipeline judged native lowering available from imports alone. The binding no longer touches the shim at import, and native lowering now takes its availability from the shim artifact: a blocked module reports E5092 naming the stale shim, and `jac native build llvm-shim` repairs it.
