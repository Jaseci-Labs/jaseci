- **Serve: commits no longer re-serialize loaded nodes that cannot have changed**: every commit used to serialize and hash every node and edge a request had loaded, three times per request and on read-only requests too, to catch in-place changes. Field writes are already tracked, so a loaded anchor whose fields are all immutable (numbers, strings, bytes, dates, UUIDs, enums, and tuples of those) is now skipped; anchors holding lists, dicts or other objects are still scanned for in-place changes.
