- **Fix: a `Protocol[...]` base makes a protocol**: a class declared with a subscripted `Protocol[...]` base, such as `AbstractContextManager`, `os.PathLike` or `Awaitable`, was not recognised as a protocol, so `ExitStack().enter_context(open(path))`, `enter_context(patch.object(...))` and any user context manager failed with E1053. Generic protocols now match structurally, with their type variables solved from the members.
