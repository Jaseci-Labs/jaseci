- **Performance: `rc` native builds inline the refcount fast path**: every release of an owned reference went through `__rc_release_simple`, which wrapped the full release, destructor call, free and live-list unlink included. Inlined, each release carried all of that code, and in large functions LLVM stopped inlining it, so even a plain decrement became a call. Under `[memory] profile = "rc"`, retain and the plain decrement are now always inlined, and only a release that drops the last reference, or runs once threads have started, calls the out-of-line release. An interpreter loop with 96 cases runs 6–8% faster with 24% less machine code, and js_engine's vite build of the site runs 1.9% faster with a 5% smaller library. The default `managed` profile and `nogc` are unchanged.
