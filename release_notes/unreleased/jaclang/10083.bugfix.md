- **Fix: compiling a module that may be placed native no longer re-analyzes every import from source**: a module whose native placement was still open asked for full syntax trees of every dependency, which turned off the interface cache for the rest of its compile. A program that imports the compiler (most compiler tests, and tools built on `JacProgram`) then parsed and analyzed `unitree`, `program`, the type evaluator and the rest from source on every compile, only to be placed in Python. Native placement now asks for full trees only of what native lowering reads: Jac modules outside the compiler's package, and the native standard library. Every other dependency is read from its interface, and the compiler test suite is back to its speed before placement moved after typing.
