- **A dev checkout reports its real version**: `jac --version` and everything keyed on it (the docs version label, serve manifests) read the version from the nearest `jaclang` manifest above the source tree, which now lives in the repo-root `jac.toml`. A 0.38.0 checkout used to report the stale 0.16.7 from leftover package metadata.
- **A swallowed read-only retry no longer commits half an attempt**: a unit's first write on a read-only snapshot raises `ReadOnlyRetry` so the server re-runs it at SERIALIZABLE, but a broad `except Exception` in user code (a scheduled sync, for one) swallowed it, the attempt carried on over the rolled-back transaction, and writes after the swallow were committed alone. The session now raises the retry again at the unit's exit after discarding the rest of the attempt, so the re-run still happens.
