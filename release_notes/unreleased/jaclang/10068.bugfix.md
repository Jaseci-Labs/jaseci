- **Fix: a dev hot reload no longer fails with "Cannot release compiler state during compilation" or leaves the compiler stuck**: The hot reloader re-prepared the app on the watcher thread while the first request after the change reloaded the entry module on its own thread, which ran a second preparation. When they overlapped, the reload failed with that error, and the compiler's nesting counter could be left above zero, so every later reload failed the same way until a restart. Preparations now run one at a time, and the nesting counter counts compiles up and down, so compiles that finish out of order on different threads return it to zero.
