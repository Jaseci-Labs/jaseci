- **Fix: booting a sealed bundle no longer disassembles every module to find its imports**: a sealed boot (`jac run app.jab`, every pod start of a `jac scale` deploy) decoded the bytecode of each module it loaded to find what it imports, which was most of the boot. The seal now records each module's imports in the bundle and the boot reads them; bundles sealed before this change still boot, decoding as before.
