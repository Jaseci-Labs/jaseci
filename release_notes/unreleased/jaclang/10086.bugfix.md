- **Fix: `jac native build` accepts per-target artifact names**: the advice a missing static musl runtime or C floor gives, `jac native build musl@linux-x86_64`, was rejected as an unknown artifact. `jac native` now accepts `<artifact>@<os-arch>` for a known artifact, so the advised command works and `jac native build musl@linux-aarch64` builds the runtime for another target.
