- **Fix: a builtin exception raised with a number lowers natively**: `raise SystemExit(3)`, `raise ValueError(n)` or `raise RuntimeError(flag)` in native code failed the whole function with a backend `TypeError` (E5092), because the argument was passed through as the message pointer. A scalar argument is now converted to its text, as `str(exc)` renders it in Python; an argument with no native text form makes the function run on the Python side instead of crashing.
