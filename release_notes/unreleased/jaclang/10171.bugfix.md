- **Fix: native lowering cost scales with the unit, not with its import closure**: lowering one unit of a native build used to analyze every module its imports reach, transitively, and paid a near-constant few seconds per unit plus long collector pauses as the session's heap grew. Dependency discovery now follows only a unit's own imports, analyzes nothing, and runs before any IR is built. Each unit's IR crosses into LLVM once and moves between LLVM contexts as bitcode. The native-only check reads the fallbacks the lowering recorded instead of rescanning printed IR. The build session holds the compile-time collector thresholds and freezes what it keeps at each unit boundary. `jac native build kernel --stop-after N` times an uncached kernel build up to its Nth lowered unit and reports the phase split, collector pauses, failures and per-unit lowering time.
