- **Fix: the native kernel seal lowers each unit's dependencies before it, not inside its pass**: lowering a native unit asked for each imported unit's interface while walking its imports, and a dependency with no entry yet was lowered inside the consumer's pass. Every consumer down the import chain then kept its partial IR alive (94 passes and 9M instructions at once), so sealing the compiler kernel peaked near 45 GB and was killed on CI. A missing dependency is now recorded, the consumer's pass stops before emitting code, and the dependency is lowered to completion first. Peak memory over the kernel closure falls to about 13 GB.
