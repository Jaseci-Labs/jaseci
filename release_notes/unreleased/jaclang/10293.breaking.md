- **Breaking: a boolean `JAC_SERVE_*` variable must be a true/false word, and an empty one is unset**: `JAC_SERVE_DOCS`, `JAC_SERVE_GRAPH`, `JAC_SERVE_ACCESS_LOG`, `JAC_SERVE_ACCESS_LOG_SUPPRESS_HEALTH` and `JAC_SERVE_COMPRESSION` used to read every value except `0/false/no/off` as true, so an empty variable, a typo like `flase` or a word like `disabled` switched the feature on over a `jac.toml` `false`, with nothing logged. They now take `1/true/yes/on` or `0/false/no/off` (any case), the same rule the `[serve.*]` table variables already followed, and any other value stops the server with a message naming the variable. An empty or whitespace-only `JAC_SERVE_*` variable now counts as unset everywhere, so the `jac.toml` value stands: `JAC_SERVE_PORT=""` and the other number variables no longer fail the boot, and `JAC_SERVE_CORS_ORIGINS=""` no longer clears the `cors_origins` list.
