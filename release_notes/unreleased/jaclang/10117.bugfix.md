- **Fix: native `str.index`, `find`, `rfind`, `rindex` and `count` honour `start` and `end`**: natively compiled code ignored some of the positions passed to these methods and returned a different index than Python without raising. `s.index("/>", 5)` returned the first match in the whole string, `find` ignored `end`, and `rfind`, `rindex` and `count` ignored both. They now share the bytes search routine, which already follows CPython's rules; this also fixes `"aaa".rfind("aa")`, which returned 0 instead of 1.
