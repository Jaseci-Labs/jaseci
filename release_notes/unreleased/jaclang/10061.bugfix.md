- **Fix: native placement judges a module's whole import closure, however large**: a module whose import closure held more than 256 modules was placed on the server (reported only in a note), and a native entry that imported it then failed to lower with E5092. The closure walks visit each module once and need no bound, so `[build] native_closure_cap` is retired; a `jac.toml` that still sets it is warned.
