- **Fix: release binaries build again, and the macOS binary no longer aborts at startup**: the release kernel seal failed on every platform after archwire emptied `llvm/ir/__init__.jac`, because a typed-only import of a module with no code of its own was treated as a native link unit. Two new archwire checks also used constructs the native kernel cannot compile. Separately, the seal could not find the static C libraries it had just staged, so the kernel linked OpenSSL dynamically. On macOS that loaded the system's unversioned `libcrypto.dylib`, which the OS refuses, and `jac` aborted on launch. On Linux the kernel depended on the system's `libssl.so.3`.
