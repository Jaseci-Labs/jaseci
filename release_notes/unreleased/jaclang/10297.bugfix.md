- **Fix: a `finish_tool` batched with other tools no longer leaves an unanswered call in `conversation=`**: when a model called `finish_tool` in the same response as other tools, the calls after it were never answered and the saved conversation kept a tool call with no result, so strict providers rejected the next request. Calls after `finish_tool` now get a "not executed" result, `finish_tool` is stripped from a mixed message instead of only from a lone one, and a call with no result is no longer saved.
