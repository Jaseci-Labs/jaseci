- **Fix: the dev watcher ignores virtual environments and files beside a watched module**: A virtual environment inside the project that was not named `venv` or hidden (`env/`, a conda prefix) could become a watch root when a loaded module lived in its `site-packages`, and editing any `.jac` file next to a watched root-level module reloaded the app. `site-packages` is now never application code, a watched file reports only itself and its annexes, and the shared `impl/` and `test/` folders beside it report only the annexes of watched modules. One predicate, `holds_application_code`, now decides what counts as application code for the runtime, the application pipeline and the watcher.
