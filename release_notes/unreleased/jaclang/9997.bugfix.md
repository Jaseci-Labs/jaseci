- **Fix: `dict(x)` is typed by its arguments**: a call to `dict` (or a subclass such as `OrderedDict`) was typed as a bare `dict`, because `dict`'s `__new__` takes anything and the `__init__` overloads that carry the key and value types were never asked. Values read from such a dict were unchecked, and the native backend could not lower a method call on one (`dict(fields).get("k", "").strip()`), so the function fell back to Python. A class whose `__new__` leaves its type parameters unsolved now takes them from the `__init__` overload the call matches.
