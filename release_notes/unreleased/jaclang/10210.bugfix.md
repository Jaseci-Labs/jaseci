- **Fix: native builds no longer hit a `RecursionError` in the endpoint effect pass**: `EndpointEffectPass` summarizes every function depth first through its callees, and on code with long `elif` chains calling helpers with long chains of their own (js_engine's interpreter loop) it passed the compiler's recursion limit, so the native build failed. Native AOT compiles now leave the pass out: its endpoint-caching metadata is read only by client code generation and the Python backend's server calls, which a native build does not produce. Other compiles still run it.
