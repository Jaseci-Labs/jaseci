- **Fix: native string ops count codepoints, not bytes**: `len`, indexing, slicing (including views and huge or negative steps), `for`-iteration, `find`/`rfind`/`count`/`index`/`rindex`, `startswith`/`endswith`, `ljust`/`rjust`/`center`/`zfill`/`expandtabs`, `strip(chars)` and f-string `{s:N}`/`{s:.N}` now work on UTF-8 codepoints instead of bytes, malformed UTF-8 can no longer read or write past a buffer, multibyte characters read out of a string no longer leak, and a negative pad width no longer crashes the padding methods.
