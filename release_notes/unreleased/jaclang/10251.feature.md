- **The native compiler kernel is built for every release target on one builder**: native code calls a small runtime floor (`posix_floor.c`, `win_floor.c`) for whatever a C library spells or lays out differently per target, so the kernel lowers to the same code on every 64-bit target. Release builds make each platform's kernel on x86 Linux and seal it into that platform's binary (`zig build -Dkernel=DIR`), and `jac native build kernel@<osarch>` builds another target's kernel. Native `hashlib` and `hmac` are now pure Jac, so native programs no longer link OpenSSL for hashing. Fixes along the way: native `os.path` works on glibc older than 2.33, `os.listdir` reads directory names correctly on Intel macOS, and `sys.platform` is `win32` (not `windows`) on Windows.
