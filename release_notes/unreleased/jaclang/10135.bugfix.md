- **Fix: build-kit seals the native kernel again, and the checker gaps behind the failure are closed**: a dict literal keyed by enum members and indexed by a `str` stopped the kernel seal with E1053. Container literals with no expected type now widen enum members to their enum class. An `is None` or truthiness check that a value can never pass narrows that arm to `Never`.
