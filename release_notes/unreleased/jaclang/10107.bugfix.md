- **Fix: a `TypedDict` accepts only a `TypedDict` or a dict literal whose fields fit**: any value passed where a `TypedDict` was expected, because `TypedDict` assignment went through protocol matching, which compares only methods; `role_of(1)` checked clean for a `UserDoc` parameter. A source `TypedDict` must now carry every destination field at the same type, and a dict literal takes the expected `TypedDict` type only when every key is a declared field and every value fits; anything else, including a plain `dict`, is reported as E1053.
