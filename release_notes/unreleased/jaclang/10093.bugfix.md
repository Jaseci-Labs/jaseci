- **Fix: `jac run --dev` no longer watches a jac checkout inside the project**: When the compiler source sits inside the project (a submodule used through `JAC_DEV_SOURCE`), the client build's reads of jaclang's own client modules made the whole jac tree a watch root, so the dev server scanned thousands of compiler files and reloaded the app on compiler edits. Modules that are the compiler's own source never make a watch root.
