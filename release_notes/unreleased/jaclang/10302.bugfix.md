- **byLLM finds a model client installed after startup**: byLLM decided once, when it was imported, whether litellm was installed, so a command that put a project's `.jac/venv` on the path afterwards kept a stand-in and failed on its first model call. It now resolves litellm when it is used.
- **Inlay hints land after the name**: the language server placed inferred receiver modes (`(&self)`) and `raises` hints one column too far right.
- **Native code can call an optional callable**: calling a `Callable | None` value after narrowing it no longer demotes the function to Python; a call on `None` raises `TypeError` as it does in Python.
- **Demoted tests no longer block native binaries**: `jac build --native` counted a module's tests that fell back to Python as demotions in the binary, though a binary never runs them.
