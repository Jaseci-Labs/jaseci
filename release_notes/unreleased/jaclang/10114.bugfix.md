- **Fix: a for-loop iterator inside a native generator is released exactly once**: an iterator-protocol loop in a generator (`for (i, v) in enumerate(xs)`, `zip`, `map`, a call returning an iterator, or a borrowed iterator parameter) kept its iterator in a frame slot that the frame's drop released again after the loop had already released it, so an owned adapter was freed twice and a borrowed iterator lost a reference it never gave. The spill now retains a borrowed iterator and the loop clears the slot when it releases it.
