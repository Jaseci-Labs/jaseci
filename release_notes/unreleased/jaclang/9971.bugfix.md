- **Fix: a container unpacked from `enumerate` or `zip` is typed, not a `str`**: natively, `for (i, row) in enumerate(rows)` over a list of lists (or of dicts or sets) bound `row` as an untyped pointer, so `len(row)` ran the string length over the list's header and returned a wrong count, and a nested `enumerate(row)` crashed. A name unpacked from such an element is now typed as the checker typed it, as a plain loop over the list does.
