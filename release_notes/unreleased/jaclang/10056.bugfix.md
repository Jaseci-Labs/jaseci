- **Fix: `jac native build llvm-shim` works on a fresh checkout**: the shim build ran `zig build jacllvm`, but `build.zig` defines that step only after `zig build fetch-llvm` has put the pinned LLVM in `.llvm-build/`. Following the "Run `jac native build llvm-shim`" advice every jac invocation printed therefore failed with zig's `no step named 'jacllvm'` and a raw traceback. The shim build now fetches the pinned LLVM first (about 84 MB once; already-fetched LLVM is reused) and then links the shim. A host that `bootstrap/pins.json` pins no LLVM for is skipped with a reason that names the host. A failing build command in any `jac native build` artifact is now reported as a plain error that names the command, with no traceback.
