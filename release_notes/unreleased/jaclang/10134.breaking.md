- **Breaking: the wiring file is `archwire.jac`**: The file that declares a directory's module wiring is named `archwire.jac`; a file named `arch.jac` is an ordinary module again, so rename an existing one. Its `graph import` blocks report `E2088` until it is renamed. `jac arch sync --strip` also removes a function's wired import when a nested function writes the same import.
