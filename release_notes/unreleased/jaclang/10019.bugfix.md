- **Fix: `jac fix dependencies` runs on the `jac.toml` it is meant to migrate**: the CLI validated `jac.toml` before dispatching any command, so a manifest that still listed a PyPI package under `[dependencies]` made `jac fix dependencies` exit 2 with the very error that tells you to run it. A command can now declare that it tolerates an invalid manifest (`CommandSpec.tolerates_invalid_manifest`), `jac fix` does, and dispatch skips both the exit and the profile overlay for it; malformed TOML still stops `jac fix`, and every other command still refuses an invalid `jac.toml`.
