- **Breaking: archwire.jac rules are mandatory between top-level packages**: under an `archwire.jac`, a wire or written import from one top-level package into another must be admitted by an `edge` rule, or it is `E2099`, whose message carries the rule to add. A rule on the bare `*` pattern is `E2100`. `jac arch init` writes one rule per top-level package that feeds another, and `jac arch sync` admits each new edge in the rule named after its source package, never editing hand-written rules. `jac arch sync --prune` now also deletes the written import of a pruned `-->` wire, through a new lint, `W3054` (`remove-dead-import`): `jac fmt --lintfix` removes a written import under a boundary that no wire provides and nothing reads. jaclang's own `archwire.jac` gains rules describing its current layering.
