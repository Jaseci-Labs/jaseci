- **Breaking: the native compiler kernel is built only by `jac kernel build`**: resolving the kernel never builds one. A source checkout runs the kernel built from its current sources (its own, or the one in the kit it runs on, loaded in place); otherwise every `jac` process, the language server included, runs the compiler from bytecode and says so once on stderr, naming why and pointing at `jac kernel build`. Previously a stale checkout started an hour-long kernel rebuild in a child process behind a lock, silently, from whichever process looked first. `jac kernel status` lists what moved since the kernel was built and which kernel the process runs; `jac kernel build [--force]` builds it, reusing unchanged units. The `JAC_COMPILER_LIB` switch is removed in both its `off` and path forms (a stale checkout already runs from bytecode), and the sidecar no longer records the folded `source_key`. Released (sealed) builds are unchanged and always run the kernel they ship with.
