- **Fix: placement gaps left after placement moved after typing**: a dict key spelled as a `str` alias (`TypeAlias`, `type Key = str`, `typing.Text`, a `Literal` of strings) in a function a client calls is no longer reported as `E5115`. A function in a module placed part native and part Python that the native backend refuses only while lowering it no longer leaves a Python stub that aborts the process when called; the module is compiled on the server instead. An overload a call only tried, and did not select, no longer forces the caller native. Importing a native standard-library type alias (`contextvars.Token`) no longer keeps the module in Python. A construct that cannot be native inside a method of an archetype pinned native is now an error instead of being moved to Python silently.
