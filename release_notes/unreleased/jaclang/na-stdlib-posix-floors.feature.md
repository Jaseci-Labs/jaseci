- **Bundled native stdlib gains the POSIX terminal floors `fcntl`, `termios`, `tty`, and `select`**: The same `import fcntl` / `import termios` / `import tty` / `import select` binds CPython on the Python backend and the bundled `na_stdlib` module on the native backend. `fcntl` covers `fcntl(fd, cmd, arg=0)` (the `F_GETFL`/`F_SETFL` family) and buffer `ioctl` (the packed `winsize` for `TIOCGWINSZ`); `termios` ships the CPython-shaped `tcgetattr`/`tcsetattr` over `[iflag, oflag, cflag, lflag, ispeed, ospeed, cc]` over a per-OS FFI floor (glibc's 60-byte `u32`-word layout and Libsystem's 72-byte `u64`-word layout, with libc speed accessors and per-OS constant values); `tty` ports CPython's `setraw`/`setcbreak` verbatim; `select` runs over `poll(2)` with the `-1.0` block-forever sentinel. Documented divergences: errors raise `ValueError` carrying CPython's `[Errno N] <strerror>` text where CPython raises `OSError`/`termios.error`/`select.error`; `ioctl` answers the buffer back; `select` reports `POLLERR`/`POLLHUP` both readable and writable and never fills the exceptional list. Each surface is pinned sv<->na congruent by `prim_fcntl`/`prim_termios`/`prim_tty`/`prim_select` equivalence fixtures; scope notes live in `na_stdlib/README.md`.
