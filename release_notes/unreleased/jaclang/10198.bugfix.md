- **Fix: a client module exports every client-placed name another client module imports** (#9131): a plain (non-`:pub`) declaration imported by another client module was exported only if the import was what moved it to the client. A glob or helper its own module's component already used, any plain JSX component, and every plain declaration in a `[placement.pins]` client module were never exported, so `jac check` passed and `jac run` failed with `runtime import(s) ... are not exported`. The import is now recorded on the declaration however it was placed, and that record survives a recompile of the module without its importer. Names nothing imports stay unexported, so component modules keep Fast Refresh. The error no longer claims `:protect` declarations cross into the bundle.
