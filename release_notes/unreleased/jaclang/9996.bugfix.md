- **Fix: `jac run app.jab --port N` serves on port N**: arguments after `jac run`'s target go to the program, so for a bundle that serves (service, web-app and similar kinds) `--port` written after the bundle, and `--port` given to a fused app binary, was dropped and the server used its configured port. A served bundle now takes `--port N` or `--port=N` from those arguments, and any other argument is refused with a message instead of being ignored.
