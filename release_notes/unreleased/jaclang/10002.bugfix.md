- **Fix: a narrowed variable keeps its narrowing where another query for it is open**: a read of a variable narrowed by an earlier `if x is None { return; }` could be typed with its declared type and reported (`Cannot access attribute "x" for type "Vec3 | NoneType"`) when resolving an assignment to the same variable elsewhere in the function forced the scope to be checked. The narrowing queries refused any query for a symbol already being resolved; they now refuse only the same symbol at the same place.
