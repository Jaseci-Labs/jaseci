- **`by llm` calls with arguments work again on 0.38**: when the native compiler kernel serialized a module's MTIR, its node lists (a function's params, an `obj` return type's fields, its tools) came out as raw bytes and were dropped on load. A `by llm` function or method that takes an argument crashed with `IndexError: list index out of range`, and structured outputs and tools reached byLLM without their metadata. The lists now survive the kernel, and a graph that still arrives with a non-reference in a node list is dropped whole rather than half-read.
