- **Fix: a module shared by several pages exports what every page pulls**: with the native compiler kernel, each page compiles in its own session, and a shared module's client exports grow as later pages use more of it. The client compiler wrote each module once, on the first page that reached it, so a later page's import of another name failed in Vite (`"spacing" is not exported by ".../tokens.js"`). Once every page has compiled, a module whose exports grew is written again.
